# Bank Transaction

Java application for parsing and handling transaction data in multiple formats.

## Overview

This project focuses on reading financial records and working with them through a common domain model.

## Build

```bash
mvn clean package
```

## Run

The project is packaged as a shaded JAR. Use the artifact from `target/` after building.
